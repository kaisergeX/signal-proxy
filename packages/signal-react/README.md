<h1>Signal React</h1>

React adapter for [`@kaiverse/signal`](https://jsr.io/@kaiverse/signal)

</div>

## Installation

No need to install the core package `@kaiverse/signal`.

### Via `npmjs`

```
npm i @kaiverse/signal-react
```

```
pnpm add @kaiverse/signal-react
```

### Via `jsr`

```
deno add jsr:@kaiverse/signal-react
```

```
npx jsr add @kaiverse/signal-react
```

```
pnpm dlx jsr add @kaiverse/signal-react
```

### Via CDN:

```
unpkg.com/@kaiverse/signal-react
```

## Compatibility

Signal is a [`Proxy`](https://developer.mozilla.org/docs/Web/JavaScript/Reference/Global_Objects/Proxy) object at its core, please check [compatibility section](https://developer.mozilla.org/docs/Web/JavaScript/Reference/Global_Objects/Proxy#browser_compatibility).
